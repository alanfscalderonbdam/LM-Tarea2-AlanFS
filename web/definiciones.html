Definiciones

Esta es una página HTML simple que sirve para ....

< html >
Contenedor que envuelve todo el documento. link
< head >
Contiene información que el usuario no ve. link
< title >
Indica el título de la página en la pestaña del navegador. link
< meta >
Indica información adicional y configuraciones de la página. link
< body >
Indica la información visible que se le va a mostrar al usuario. link
< header >
Etiqueta de sintaxis que indica la parte superior de la página. link
< h1 >
Crea el titulo 1 de la pagina (principal). link
< h2 >
Crea el titulo 2 (secundario). link
< h3 >
crea el titulo 3 (terciario y asi sucesivamente). link a otra pagina
< p >
Se usa para crear un párrafo. link
< nav >
Indica los enlaces de navegación dentro del sitio. link
< ul >
Crea una lista desordenada (con puntos). link
< li >
Define un elemento o ítem dentro de una lista. link
< br >
Crea un salto de línea , break row. link
< main >
Etiqueta de sintaxis que indica el contenido principal de la pagina. link
< table >
etiqueta que crea una tabla. link
< thead >
Indica el encabezado de la tabla. link
< tr >
Indica una fila horizontal dentro de la tabla tabla. link
< th >
Indica una casilla del encabezado de la tabla. link
< footer >
Etiqueta de sintaxis que indica la parte inferior de la página. link
< img >
Etiqueta para añadir una imagen en la página. link
< a >
Crea un enlace a otra pagina ubicación. link
